## 🎯 About

> This repository contains my hands-on practice solutions for **Module 18 – Problem Solving with JavaScript + ES6**.

Every task below is solved using **only the ES6 concepts covered in this module** — no external libraries, no shortcuts, no AI-generated logic. Just consistent, deliberate practice to build real fluency in modern JavaScript.

<br>

## 🧠 Concepts Covered

<div align="center">

| 🔤 Fundamentals | 🧩 Structuring | 🔁 Iteration |
|:---:|:---:|:---:|
| `const` / `let` | Object Destructuring | `map()` |
| Template Literals | Array Destructuring | `filter()` |
| Default Parameters | Spread Operator | `reduce()` |
| Arrow Functions | Rest Operator | `find()` / `every()` |
| Optional Chaining `?.` | `Set` for Uniqueness | `flat()` |
| Nullish Coalescing `??` | `Object.entries()` | `Object.keys()` / `values()` |

## ▶️ How to Run

Each file is self-contained and can be executed directly with **Node.js**:

```bash
node 18-07-grade-calculator.js
```

Clone the full repository to explore or test any task locally:

```bash
git clone https://github.com/aminulislam424842/programming-hero-module-18.git
cd programming-hero-module-18
```

<br>

## 🗂️ Naming Convention

All files follow a consistent, sequential naming pattern for quick navigation:

```
[module]-[sequence]-[task-slug].js
```

> **Example:** `18-07-grade-calculator.js` → Module `18`, Task `07`, *"Grade Calculator"*
